## ПР1. Эмулятор оболочки

Программа с графическим окном, похожим на терминал UNIX. В неё можно вводить
команды, а внутри живёт виртуальная файловая система, которая загружается из
CSV-файла и хранится только в памяти. Написана на Python, только на
стандартной библиотеке (графика на `tkinter`).

Запуск из папки `PR1` (нужен [uv](https://docs.astral.sh/uv/)):

```sh
./run.sh --vfs examples/vfs/deep.csv
```
